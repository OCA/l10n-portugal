Portuguese localization base for Payroll.

Features:

- A default "PT Payroll" salary structure
  (``l10n_pt_payroll.structure_pt``), with Portuguese salary rules
  adapted from the ``payroll`` module defaults:

  - *Vencimento Base* (``BASIC``): the contract wage.
  - *Subsídio de Alimentação* (``SA``): fixed meal allowance per worked
    day.
  - *Remuneração Bruta* (``GROSS``): base salary plus allowances.
  - *Segurança Social (Trabalhador)* (``SS``): 11% employee
    contribution.
  - *Retenção na Fonte IRS* (``IRS``): withholding tax.
  - *Segurança Social (Entidade Patronal)* (``SS_COMP``): 23.75%
    employer contribution.
  - *Líquido a Receber* (``NET``): gross minus deductions.

- Contribution registers for *Segurança Social* and *Autoridade
  Tributária e Aduaneira*.

- Demo data assigning the PT Payroll structure to the PT Company
  (``base.demo_company_pt``) employees provided by ``l10n_pt_hr``.

- IRS withholding computed with the official progressive tables
  (Despacho n.º 233-A/2026 and regional equivalents), including the n.º
  5 adjustments: dependents, disabled dependents/spouse, pensioner
  dependents, armed-forces disability, preferred rate, non-residents and
  IRS Jovem.

- Bundled 2026 withholding tables for all three regions (continente,
  Açores, Madeira) generated from the official AT Excel workbooks,
  importable/updatable through a wizard without a module release.

- Social Security contributions computed from the employee's regime
  (``l10n.pt.ss.regime``): employee TSU and employer TSU rates are
  configurable per regime, plus the work accident insurance (SAT)
  premium from the employee's insurance policy.

The contribution base is still simplified: it uses the base salary only
and excludes allowances such as the meal subsidy. That is a starting
point for a full Portuguese payroll implementation, not a legally
accurate computation.

Configuration
=============

IRS withholding determinants
----------------------------

The IRS retention inputs live on each employee version (Employees →
employee → *Payroll Information* tab, right after *Disability Degree*):
family status, dependents, disabled dependents (with factor), disabled
spouse, region, pensioner, armed-forces disability, non-resident flag,
preferred rate and IRS Jovem. The region defaults from the employee's
address (Açores/Madeira districts and postal code prefixes) and can be
overridden manually.

The computed withholding table variant (I–XI) is shown read-only on the
same section for information.

IRS withholding tables
----------------------

Retention tables are data, not code: one set per (validity period,
region, table variant I–XI), stored under *Payroll → Configuration → IRS
Withholding Tables*.

**Bundled tables load only at install time.** The module's post-init
hook imports every ``data/irs/*.csv`` file once, when the module is
first installed. Upgrading the module to a version that ships new CSV
files does **not** reload them — the tables on existing databases stay
untouched. To pick up new bundled tables on an existing database, open
the *Import IRS Withholding Tables* wizard and click *Load bundled
tables* (this re-imports every bundled file and is safe to run
repeatedly — each table block is replaced, never duplicated).

To install tables that are not bundled (a newer or corrected Despacho),
upload the CSV file in the same wizard. The CSV must use the bundled
format; the official AT Excel workbooks can be converted with
``scripts/xlsx_to_csv.py``.

Bundled CSV files are append-only: when a new year's tables ship, add
the new files but never remove previous years. Already-installed
databases keep their imported tables regardless (the loader only adds or
replaces blocks, it never deletes), but fresh installs only get what is
bundled — removing an old file would make backdated payslips
uncomputable on new databases.

Usage
=====

Assign the "PT Payroll" salary structure to employee contracts
(Employees → employee → Payroll Information → Salary Structure), or use
it as the parent structure for company specific structures.

When the database is created with demo data enabled, the PT Company
employees from ``l10n_pt_hr`` are automatically assigned this structure.
Create a payslip for one of them and click "Compute Sheet" to see the
Portuguese payslip lines.
