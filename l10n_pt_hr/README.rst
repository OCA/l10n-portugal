Portuguese localization support for Human Resources.

Features:

- Demo data for the "PT Company" (``base.demo_company_pt`` from
  ``l10n_pt``): a full set of Portuguese employees mirroring the core
  ``hr`` demo data, including a Portuguese department tree, work
  location, working schedule, contract versions and department managers,
  with Portuguese job titles.
- Extra translations (``i18n_extra/pt.po``) for the core demo Job
  Positions used by the demo data.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

Demo employees
--------------

When the database is created with demo data enabled, the module adds a
full set of employees to the "PT Company" demo company. Switch to that
company and open Employees to see them.

Load testing
------------

To create large numbers of employees for load testing, use the
``odoo populate`` command, which duplicates the existing demo employees:

.. code:: console

   $ odoo populate -d <database> --models hr.employee --factors 100
