Portuguese localization support for Human Resources.

Features:

- Demo data for the "PT Company" (`base.demo_company_pt` from `l10n_pt`):
  a full set of Portuguese employees mirroring the core `hr` demo data,
  including a Portuguese department tree, work location, working schedule,
  contract versions and department managers, with Portuguese job titles.
- Extra translations (`i18n_extra/pt.po`) for the core demo Job Positions
  used by the demo data.
