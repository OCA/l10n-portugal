Provides Annual Leave and the default Portuguese absence types needed to
distinguish the active reasons in Relatório Único Table 10. It uses
Odoo's standard requests, approvals, allocations, and work calendars.
This addon does not generate public holidays, calculate payroll, or
submit declarations.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

1. In Time Off, set up the public holidays on your Portuguese work
   calendars.
2. Create and approve Annual Leave allocations for eligible employees.
   Check each employee's entitlement before allocating days. The module
   does not grant days automatically.
3. Review the default approval settings for Annual Leave in Time Off
   configuration.
4. Use the most specific Portuguese absence type when recording an
   absence. The default types do not determine whether an absence is
   paid or automatically prepare a report.
5. In Time Off > Reporting > Vacation Schedule, choose the year, then
   print the current Portuguese company's approved annual leave periods.
   Review and post the schedule at the workplace.
