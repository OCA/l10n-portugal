Generates Portuguese nationwide public holidays in the OCA holiday
catalog using editable fixed-date and Easter-relative rules. It is
independent of Portuguese Time Off and Payroll addons. It does not
create native work calendar closures.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

1. Open Time Off > Configuration > Public Holidays (OCA) > Portuguese
   Holiday Rules to review the seeded rules.
2. Use Generate Portuguese Public Holidays to preview and apply a year.
   Select Carnival only if it applies nationwide for your deployment.
3. Use Last Year's Optional Rules to carry forward linked rules, not
   one-off dates. Use the Portuguese wizard rather than OCA's generic
   next-year copy for Portugal.
4. Configure regional holidays separately in the OCA catalog. Keep
   company-only closures on native Odoo work calendars and never
   register the same holiday in both catalogs.
