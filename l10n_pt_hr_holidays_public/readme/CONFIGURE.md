1. Open Time Off > Configuration > Public Holidays (OCA) > Portuguese Holiday Rules to review the seeded rules.
2. Use Generate Portuguese Public Holidays to preview and apply a year. Select Carnival only if it applies nationwide for your deployment.
3. Use Last Year's Optional Rules to carry forward linked rules, not one-off dates. Use the Portuguese wizard rather than OCA's generic next-year copy for Portugal.
4. Configure regional holidays separately in the OCA catalog. Keep company-only closures on native Odoo work calendars and never register the same holiday in both catalogs.
