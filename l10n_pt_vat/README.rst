Keep the legacy ``l10n_pt_vat`` models and catalog data installable on
Odoo 20 so upgraded databases preserve their VAT adjustment norms,
exemption reasons and document links unchanged. The module provides no
views or business logic; the replacement features live in
``l10n_pt_account_vat`` and ``l10n_pt_account_invoice``, which have no
dependency on this module. It is not meant for new deployments and can
be uninstalled once the upgrade has been verified.

Installation
============

**Upgrading an existing database**

After the compatible Odoo 20 core upgrade, update the installed
``l10n_pt_vat`` module on an upgrade copy of the database:

.. code:: bash

   odoo-bin -d <upgrade-copy> -u l10n_pt_vat --stop-after-init

Then install or update the successor addons separately:

.. code:: bash

   odoo-bin -d <upgrade-copy> -i l10n_pt_account_vat,l10n_pt_account_invoice --stop-after-init

Only uninstall ``l10n_pt_vat`` after verifying the copied data in the
successors; its original records then remain removable without affecting
them. This module is not for new deployments and has no dependency on
either successor.
