1. Install the addon for the legal document provider you want to use.
   This framework does not include any providers by itself.
2. Configure the provider for the Portuguese company using the provider
   addon's instructions. Credentials, document defaults and email
   settings, where applicable, belong to that addon.
3. Go to **Accounting > Configuration > Journals** and open a sales
   journal for the Portuguese company. Select the provider in
   **Legal Document Provider** — only providers whose adapter addon is
   installed appear in the selector — complete any additional journal
   fields required by that provider, and save. Repeat for each sales
   journal that should use a provider.

Leave **Legal Document Provider** empty on journals that should not
send documents to an external service.
