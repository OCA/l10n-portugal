On Accounting Tax Groups, the "Region (PT)" and "Tax Category (PT)" are set
automatically for the standard Portuguese chart of accounts, and can be
reviewed at *Accounting/Invoicing > Configuration > Accounting / Tax Groups*:

- The Region identifies the VAT zone: Continental Portugal, Madeira,
  Azores, or all regions.
- The Tax Category is the SAF-T code: Normal, Intermediate, Reduced or
  Exempt.

On Accounting Taxes, the "Tax Exemption Reason" can be set, and is required
for Portuguese taxes with a 0% amount.

The default VAT Exemption reason can be set on the Sales Journal:

- Go to *Accounting/Invoicing > Configuration > Accounting / Journals*
